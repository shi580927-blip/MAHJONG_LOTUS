# Stage 3 — как провести EXP-301

Файл теста: `validation/idea_test.html`.

## Как запускать
1. Скачать `idea_test.html`.
2. Открыть файл в современном браузере.
3. Выдать участнику анонимный код: T01, T02, T03...
4. Не объяснять механику сверх текста, который уже показан в тесте.
5. Не подсказывать, какие плитки нажимать.
6. После первого уровня не убеждать продолжать — выбор «Да, ещё один уровень» должен быть добровольным.
7. После опроса скопировать JSON результата.
8. Перенести данные в `stage3_results_template.csv`.

## Что нельзя делать
- не показывать production-арт до проверки первых минут, если тестируется чистый core loop;
- не помогать участнику во время уровня;
- не менять правило между участниками;
- не считать знакомых автора единственной выборкой;
- не объединять результаты разных версий прототипа без отметки версии.

## Минимум
Нужно 20 участников. До этого Этап 3 не закрывается.
