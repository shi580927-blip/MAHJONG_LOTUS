# YANDEX_GAMES_CHECKLIST.md

> Обязательный контрольный чеклист проекта **«Маджонг: Путь Лотоса»** перед тестовой загрузкой, модерацией и каждым релизом в Яндекс Играх.
> Версия чеклиста: 2026-09-20.
> Основание: актуальные требования и документация Яндекс Игр + ранее отработанный внутренний чеклист публикации.

## Правило использования

Проверка выполняется как отдельный release/compliance gate и не заменяет этапы проекта.

Обязательные точки проверки:
- Этап 7 — Техническая архитектура: требования должны быть заложены в архитектуру.
- Этап 10 — Вертикальный срез: первая фактическая проверка SDK, адаптива, загрузки и gameplay events.
- Этап 13 — Тестирование: полный прогон чеклиста.
- Этап 15 — Подготовка релиза: повторный полный прогон перед отправкой на модерацию.
- Перед каждой последующей загрузкой ZIP: regression-прогон применимых пунктов.

Нельзя отмечать пункт выполненным без фактической проверки в сборке или черновике Яндекс Игр.

## 1. Названия и локализация

Утверждённые названия:
- RU: **Маджонг: Путь Лотоса**
- EN: **Mahjong: Lotus Path**
- TR: **Mahjong: Lotus Yolu**

- [ ] Для RU, EN и TR название в самой игре полностью совпадает с названием в соответствующей языковой вкладке черновика.
- [ ] Название на каждом языке совпадает на обложке, скриншотах, видео и других промоматериалах, если название там отображается.
- [ ] Перед отправкой на модерацию повторно проверена уникальность названия в каталоге Яндекс Игр для каждого заявленного языка.
- [ ] Все значимые игровые тексты переведены на заявленные языки.
- [ ] Язык определяется при запуске через SDK Яндекс Игр.
- [ ] Для `tr` включается турецкая локализация.
- [ ] Для `ru` включается русская локализация.
- [ ] Для `en` включается английская локализация.
- [ ] Для неподдерживаемых языков используется согласованный fallback: русский для be/kk/uk/uz, английский для остальных.
- [ ] Если есть ручное переключение языка, до него можно добраться без знания текущего языка; названия языков понятны сами по себе.

- [ ] Версия увеличена относительно предыдущей загруженной сборки.
- [ ] В корне ZIP находится один `index.html`.
- [ ] Содержимое архива до сжатия не превышает **100 МБ**.
- [ ] В именах файлов и папок нет кириллицы и пробелов.
- [ ] В архиве нет `.git`, исходников промоматериалов, тестовых документов, временных файлов и ненужных ассетов.
- [ ] Кеширование изменённых JS/CSS/asset-файлов не подсовывает старую версию.
- [ ] Архив распаковывается без ошибок.
- [ ] Игра стартует из финального ZIP, а не только из dev-среды.
- [ ] JavaScript/TypeScript сборка не содержит критических ошибок.
- [ ] В консоли браузера нет ошибок, блокирующих gameplay, SDK, сохранения или рекламу.

## 3. SDK Яндекс Игр

- [ ] Официальный SDK подключён до вызова `YaGames.init()`.
- [ ] `YaGames.init()` успешно завершается.
- [ ] `LoadingAPI.ready()` вызывается только после загрузки необходимых ресурсов и исчезновения собственного загрузочного экрана.
- [ ] В debug-панели Game Ready становится зелёным и не срабатывает по timeout.
- [ ] `GameplayAPI.start()` вызывается непосредственно при старте/возобновлении игрового процесса.
- [ ] `GameplayAPI.stop()` вызывается при завершении уровня, паузе, открытии меню, показе полноэкранной/rewarded-рекламы и уходе со вкладки.
- [ ] После возврата к gameplay корректно вызывается `GameplayAPI.start()`.
- [ ] События pause/resume не ломают собственное состояние игры.
- [ ] Автоопределение языка через SDK проверено в debug-панели.

## 4. Адаптивность и управление

- [ ] Desktop 16:9 работает корректно.
- [ ] Вертикальная мобильная версия работает корректно.
- [ ] Если в черновике заявлена ориентация «Любая», игра реально работоспособна в обеих ориентациях.
- [ ] Проверены разные ширины/высоты окна, включая сжатие игрового контейнера.
- [ ] Значимые кнопки, тексты, плитки, счётчики валют, предупреждения о рекламе и бустеры не обрезаются и не перекрываются.
- [ ] Игровые плитки остаются читаемыми и достаточно крупными для тапа на телефоне.
- [ ] На мобильных устройствах нет случайного масштабирования/выделения текста, мешающего игре.
- [ ] Системное контекстное меню браузера не появляется в игровой области при правом клике/долгом нажатии.
- [ ] Проверены минимум desktop, Android mobile и изменение размера окна; iOS проверяется до объявления поддержки iOS.

## 5. Основной gameplay маджонга

- [ ] Свободная плитка определяется корректно: сверху нет блокирующей плитки, хотя бы одна боковая сторона свободна.
- [ ] Несвободные плитки нельзя выбрать как допустимый ход.
- [ ] Одинаковая допустимая пара удаляется ровно один раз.
- [ ] Разные символы не удаляются как пара.
- [ ] После удаления пары правильно пересчитывается доступность соседних плиток.
- [ ] Уровень завершается только после очистки требуемой раскладки.
- [ ] Нельзя получить зависание из-за состояния без ходов без предусмотренной логики восстановления.
- [ ] Решаемость уровней подтверждена генерацией/валидатором или контролируемым алгоритмом.
- [ ] Повторный запуск уровня восстанавливает корректное начальное состояние.
- [ ] Карта открывает следующий уровень только по правилам прогрессии.
- [ ] На карте корректно отображаются пройденные, текущий и закрытые уровни.
- [ ] Прокрутка карты не теряет активную точку и работает в landscape/portrait.

---

## 6. Бустеры

### Подсказка
- [ ] Показывает реально доступную пару.
- [ ] Не указывает заблокированную/невозможную пару.
- [ ] Ресурс списывается один раз.

### Перемешать
- [ ] Не удаляет плитки и не меняет число оставшихся пар.
- [ ] После перемешивания создаётся корректное игровое состояние.
- [ ] Исключено бесконечное бесплатное использование, если бустер ограничен экономикой.

### Благословение Лотоса
- [ ] Удаляет только допустимую пару.
- [ ] Не ломает решаемость оставшейся раскладки.
- [ ] Списание ресурса и визуальная награда происходят один раз.

---

## 7. Валюты и экономика

- [ ] Используются две утверждённые валюты: монеты и лепестки.
- [ ] «Лотосы» не используются как название валюты.
- [ ] Все начисления происходят один раз.
- [ ] После перезапуска баланс не удваивается.
- [ ] Rewarded-реклама не позволяет бесконечно фармить валюту.
- [ ] Нельзя бесконечно повторять удвоение одной и той же награды.
- [ ] Источники и траты обеих валют соответствуют утверждённой таблице экономики.
- [ ] Баланс не уходит в отрицательные значения без специальной механики.

---

## 8. Rewarded и interstitial-реклама

- [ ] До запуска rewarded игрок ясно видит, что будет реклама и что он получит.
- [ ] Rewarded запускается только после осознанного действия пользователя.
- [ ] Во время полноэкранной/rewarded-рекламы gameplay и звук остановлены.
- [ ] После полного rewarded-просмотра награда выдаётся один раз.
- [ ] При закрытии/ошибке до подтверждённого вознаграждения награда не выдаётся.
- [ ] Работают собственные проектные caps/cooldown.
- [ ] Один и тот же экран победы не позволяет бесконечно получать повторные рекламные награды.
- [ ] Нельзя строить циклы «реклама → награда → ещё реклама» без установленного лимита.
- [ ] Interstitial вызывается только в естественных паузах между состояниями, не в момент взаимодействия с плитками.
- [ ] Реклама проверена внутри черновика Яндекс Игр.
- [ ] После закрытия рекламы игра корректно возвращается в предыдущее состояние.

Примечание: платформа сама управляет частотой полноэкранных рекламных блоков, но проект дополнительно применяет собственные ограничения ради UX и защиты от фарма.

---

## 9. Звук, пауза и фокус

- [ ] Музыка и эффекты имеют понятное управление.
- [ ] Настройки звука сохраняются.
- [ ] При уходе со вкладки/сворачивании gameplay и звук останавливаются.
- [ ] Во время рекламы звук игры отсутствует.
- [ ] После возврата звук восстанавливается только если был разрешён игроком.
- [ ] Одновременные эффекты не создают резких пиков громкости.

---

## 10. Сохранения

- [ ] Сохраняются: прогресс уровней, открытые главы, монеты, лепестки, количество бустеров и настройки.
- [ ] После перезагрузки не теряется подтверждённая победа.
- [ ] Повторная загрузка не начисляет награду за уже завершённый уровень повторно.
- [ ] Локальное и облачное сохранение не создают цикл взаимного отката.
- [ ] Если в черновике отмечены облачные сохранения, они реально работают через SDK.
- [ ] В случае ошибки облака игра остаётся работоспособной с безопасным локальным fallback.
- [ ] Тестовые данные отделены от production-прогресса.

---

## 11. Визуал и производительность

- [ ] Фоновые эффекты (вода, кои, лепестки, блики, дымка) не мешают считывать плитки.
- [ ] Активная/доступная/выбранная плитка визуально различима.
- [ ] Glow и частицы не создают ложного ощущения доступности заблокированных плиток.
- [ ] На слабом мобильном устройстве нет критических просадок FPS.
- [ ] Нет утечек памяти при многократном переходе уровень → карта → уровень.
- [ ] Тяжёлые изображения сжаты/масштабированы под реальное использование.
- [ ] Ненужные полноэкранные ассеты не загружаются одновременно.
- [ ] Финальный размер остаётся в пределах лимита Яндекс Игр и внутреннего бюджета проекта.

- [ ] Название каждой локали не превышает 50 символов и начинается с заглавной буквы.
- [ ] Название уникально в каталоге для каждого заявленного языка.
- [ ] «Об игре» и «Как играть» соответствуют реальной механике.

- [ ] Иконка/обложка не являются скриншотами игры.
- [ ] Обложка: **800×470 PNG**.

- [ ] Desktop-скриншоты — 16:9.
- [ ] Mobile — 9:16 для портретной версии или 16:9 для выбранной мобильной ориентации.
- [ ] Длинная сторона скриншота 1280–2560 px.
- [ ] Не менее 2 скриншотов для каждой заявленной платформы.
- [ ] На скриншотах нет системного UI, UI Яндекс Игр, тестовых панелей и браузерных элементов.
- [ ] Нет артефактов генерации/сжатия, обрезанного текста, рамок или скруглённых углов.
- [ ] Промоматериалы относятся к реальной игре и не показывают чужой gameplay.
- [ ] Если подготовлено вертикальное gameplay-video: 9:16, MP4, высота от 400 px, до 28 сек, до 100 МБ.
- [ ] Если подготовлено горизонтальное gameplay-video: 16:9, MP4, высота от 400 px, до 28 сек, до 100 МБ.
