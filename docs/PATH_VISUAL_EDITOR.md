# PATH VISUAL EDITOR — Маджонг: Путь Лотоса

**Статус:** TEST / внутренний инструмент расстановки  
**Добавлено:** 2026-10-05

Редактор не является игровым экраном и не утверждает production layout автоматически. Его задача — дать возможность вручную расставить 60 нод Пути поверх текущего review-фона, отдельно для двух design frame.

## Вход

- Landscape 16:9: `?screen=map&edit=1&art=1&frame=landscape`
- Portrait 9:16: `?screen=map&edit=1&art=1&frame=portrait`

На GitHub Pages ссылки также доступны в верхней TEST-плашке.

## Управление

- перетащить ноду мышью / пальцем — изменить её положение;
- тянуть пустую область карты — прокручивать Путь;
- колесо мыши — прокрутка Пути;
- **Сохранить** — записать координаты текущего формата в localStorage браузера;
- **Скачать JSON** — выгрузить один файл с сохранёнными координатами landscape и portrait;
- **16:9 / 9:16** — переключить design frame;
- **Сбросить** — вернуть текущий формат к программной тестовой раскладке;
- **Готово** — сохранить и вернуться в обычный review карты.

## Хранение

Ключ localStorage: `lotus.path-editor.v1`.

Экспорт: `lotus-path-layout.json`, schema `mahjong-lotus-path-layout/v1`.

Координаты хранятся в локальной системе прокручиваемого Path world. Номер уровня остаётся программным, порядок 1→60 не меняется. Дорожка перестраивается автоматически по текущим координатам.

## После ручной расстановки

JSON считается **TEST / на проверку**. После визуального утверждения координаты переносятся в production data-файл карты и только затем получают APPROVED-статус.
