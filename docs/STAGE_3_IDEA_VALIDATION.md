# ЭТАП 3 — ПРОВЕРКА ИДЕИ

**Проект:** «Маджонг: Путь Лотоса»  
**Статус:** IN PROGRESS — эксперимент определён, измеримые результаты ещё не получены.  
**Основание:** цикличный регламент требует до перехода к Этапу 4 получить измеримый результат эксперимента.

## 1. ГИПОТЕЗА

Главная проверяемая гипотеза:

**Игрокам нужен не просто красивый Mahjong Solitaire, а спокойный короткий игровой цикл, который хочется повторять ради самого решения пар и ради видимого продвижения по «Пути Лотоса».**

Проверяем четыре подгипотезы:

- H3-01 — правило свободных пар понятно в первые минуты;
- H3-02 — базовый core loop приятно повторять без таймера, жизней и внешнего давления;
- H3-03 — после первой короткой партии возникает желание сыграть ещё один уровень;
- H3-04 — «Путь» и изменение мира усиливают продолжение игры и воспринимаются как отличие, а не просто декор.

## 2. ЧТО НЕ ПРОВЕРЯЕМ НА ЭТОМ ЭТАПЕ

Чтобы не смешивать причины результата, эксперимент не проверяет:
- финальную экономику;
- роли монет и лепестков;
- rewarded/interstitial-рекламу;
- магазин и IAP;
- 60 уровней целиком;
- финальный баланс сложности;
- production-art и финальную анимацию;
- RU/EN/TR качество локализации;
- техническую архитектуру Phaser 3.

Эти решения остаются на последующих этапах.

## 3. ЭКСПЕРИМЕНТ

### EXP-301 — First 5 Minutes / One More Level

Тип: серый игровой прототип + короткий концепт-тест.

Минимальная версия:
1. Старт без регистрации.
2. Одна строка правила: «Выбирайте две одинаковые свободные плитки. Плитка свободна, если сверху её ничего не закрывает и хотя бы один бок открыт».
3. Первый короткий уровень на 1–3 минуты.
4. После победы — выбор без подсказки исследователя: «Ещё один уровень» / «Закончить».
5. При выборе продолжения — второй уровень немного сложнее.
6. Затем показать утверждённое визуальное обещание «Пути Лотоса»: карта + изменение мира после прогресса.
7. Короткий опрос.

### Почему не лендинг первым

Лендинг хорошо измерит привлекательность обещания, но не проверит игровую ценность. Для Mahjong главный риск — не «понимают ли красивую картинку», а «приятно ли реально убирать пары и хочется ли повторить сессию».

## 4. АУДИТОРИЯ ЭКСПЕРИМЕНТА

Минимум: **20 участников**.

Желательное распределение:
- 10 человек, которые играют в casual puzzle / tile / mahjong хотя бы иногда;
- 10 человек, которые играют в casual-игры, но Mahjong не является их регулярной игрой.

Желательно иметь заметную долю пользователей 35+, но не превращать это в жёсткий фильтр: точная демография Яндекс Игр на Этапе 2 не доказана.

Не использовать только знакомых разработчика/автора игры — это даст завышенную позитивность.

## 5. ЧТО СЧИТАЕТСЯ ИНТЕРЕСОМ

Поведенческие сигналы важнее слов:

1. Игрок самостоятельно делает первую корректную пару.
2. Игрок завершает первый короткий уровень.
3. После победы выбирает «Ещё один уровень».
4. Играет второй уровень без внешнего принуждения.
5. После демонстрации Пути говорит, что прогресс/изменение мира усиливает желание продолжать.
6. Готов попробовать игру в Яндекс Играх.

## 6. МЕТРИКИ

Для каждого участника фиксировать:

| Метрика | Как измерять |
|---|---|
| TTFP — Time to First Pair | секунд от появления поля до первой корректной пары |
| Invalid taps | количество нажатий на заблокированные/неподходящие плитки до первой пары и за уровень |
| First level completion | завершил / не завершил |
| First level time | секунды |
| One More Level | выбрал второй уровень / отказался |
| Clarity | оценка 1–5 |
| Pleasantness | оценка 1–5 |
| Continue Intent | оценка 1–5 |
| Path Appeal | оценка 1–5 |
| Try on Yandex | Да / Скорее да / Скорее нет / Нет |
| Unprompted recall | что участник назвал главным отличием своими словами |
| Friction | что раздражало / мешало |

## 7. ПОРОГИ УСПЕХА

### Hard gate — понятность
- не менее **80%** участников делают первую корректную пару без объяснений сверх одной строки;
- медиана TTFP — **≤ 30 секунд**;
- не более **20%** участников сообщают, что правило «свободной плитки» осталось непонятным после первой минуты.

Если hard gate не пройден, нельзя маскировать проблему красивым визуалом.

### Core-loop gate
- не менее **75%** завершают первый уровень;
- не менее **60%** после победы добровольно выбирают «Ещё один уровень»;
- медиана Pleasantness — **≥ 4/5**;
- медиана Continue Intent — **≥ 4/5**.

### Differentiation gate
После демонстрации Пути:
- не менее **60%** дают Path Appeal **4–5/5**;
- не менее **40%** без подсказки упоминают путь, изменение мира, открытие сада/храма или визуальное продвижение как запомнившийся элемент.

### Market-intent signal
- доля «Да» + «Скорее да» на «Попробовали бы в Яндекс Играх?» — **≥ 65%**.

Это не прогноз будущего retention и не замена реальному soft launch; это пороги ранней проверки идеи.

## 8. ИНТЕРПРЕТАЦИЯ

### GO
Можно готовить Этап 4, если:
- hard gate пройден;
- One More Level ≥ 60%;
- минимум 3 из 4 блоков: clarity / core loop / Path / try-intent проходят порог;
- нет повторяющейся критической проблемы, делающей игру неудобной.

### MODIFY
Не отбрасывать идею, а переделать конкретную часть, если:
- core loop проходит, но Path не воспринимается как отличие;
- интерес есть, но плитки/доступность считываются плохо;
- игра нравится после объяснения, но первые 30–60 секунд непонятны;
- визуал привлекает, но «ещё один уровень» выбирают <60%.

После изменения повторить тот же тест на новой группе.

### STOP / PIVOT
Не переходить к полноценной концепции в текущем виде, если:
- первую пару самостоятельно делает <50%;
- первый уровень завершает <50%;
- «Ещё один уровень» выбирает <40%;
- Continue Intent имеет медиану <3/5;
- визуальный Path не компенсирует слабый core loop.

## 9. ПЛАН ПРИ ОТРИЦАТЕЛЬНОМ РЕЗУЛЬТАТЕ

| Проблема | Действие |
|---|---|
| Не понимают свободные плитки | упростить первую раскладку и onboarding, увеличить визуальную разницу free/blocked |
| Много промахов | увеличить плитки/hit-area, снизить фоновый шум |
| Не хотят второй уровень | пересмотреть темп, форму раскладок и момент награды |
| Core нравится, Path не цепляет | переработать визуальную трансформацию мира, не добавляя новые системы |
| Path нравится, core скучный | сначала улучшать раскладки/ритм, а не расширять метаигру |
| Красиво, но не хочется играть | не идти в производство только из-за арта |
| Слишком просто | быстрее вводить слои/формы, но без таймера и искусственных штрафов |
| Слишком сложно | уменьшить стартовую плотность, дать безопасную подсказку после паузы |
